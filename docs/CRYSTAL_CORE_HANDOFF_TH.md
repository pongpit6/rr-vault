# เขตแกนผลึกเวท — ส่งต่องาน LifeQuest

## ขอบเขต

เริ่มงานจากสาขา `main` ที่มีบทเปิดใหม่ในทุ่งหญ้าลมเย็นและบทจบใหม่ที่ปราสาทเงา งานนี้เตรียมเรื่องของทวีปและปมผลึกไว้แล้ว งานต่อไปคือเพิ่มเขตแกนผลึกเวทและการล่าแบบฝูงให้เฉพาะพื้นที่ใหม่นี้

**โจทย์จากเจ้าของเกม** ใช้ร่างเรืองแสงของมอนสเตอร์เดิมครบทั้ง 120 ชนิด เจอฝูง 2–5 ตัวทุกครั้ง ฝูง 2 ตัวพบบ่อยสุด ฝูง 5 ตัวพบยากสุด ใช้อัตราดรอปเดิม และตั้งต้นพลังร่างเรืองแสงแต่ละตัวที่ ×2 เพื่อให้รับมือยาก ค่าตัวเลขและวิธีคิดด้านล่างเป็นข้อเสนอเริ่มต้นสำหรับทดสอบสมดุล

## เรื่องที่ผู้เล่นพบ

หมู่บ้านเริ่มต้นอยู่ทางใต้ของทวีป หมู่บ้านและถิ่นผจญภัยแปดแห่งเป็นขอบเขตที่แผนที่กิลด์ครอบคลุมในบทแรก ที่ปราสาทเงา ผู้เล่นคลี่ปมเสียงระฆังเก่าและนำหลักฐานกลับมาให้ปิ่นแก้แผนที่ เหมืองชั้นบนยังมีครอบครัวโคโบลด์ ส่วนทางขนแร่ชั้นล่างยังอันตราย หลังระฆังเงียบ ไพร์เห็นผลึกจากเหมืองกับโรงหลอมสว่างพร้อมกัน แนวสายแร่พ้นออกไปจากขอบแผนที่

### ข้อความเปิดพื้นที่

> ฟินหยุดตรงสะพานหินที่ข้ามร่องผา ฝั่งนี้มีรอยเท้าสัตว์หลายขนาด แต่รอยที่เดินเข้าด้านในมีน้อยกว่ารอยที่เดินกลับ ไพร์ดับตะเกียงแล้วผนังยังสว่างเป็นช่วง ๆ เหมือนผลึกสองชิ้นที่ห้องสมุด พอแสงรอบถัดไปไหลขึ้นจากก้นผา เงาที่หมอบอยู่ตามทางก็ลุกพร้อมกันหลายตัว ตัวแรกเดินอ้อมไปดักหัวสะพาน ที่เหลือออกมาจากคนละซอกหิน

ในถิ่นเดิม การแปรสภาพเกิดได้เมื่อมานาจากรอยแตกหรือกระแสไหลย้อนค้างอยู่ในร่าง แกน หรือพลังที่ยึดวิญญาณไว้ จึงมีเพียงบางตัวที่เรืองแสง ในเขตแกน มานาไหลต่อเนื่องทั้งกลางวันและกลางคืน ตัวร่างปกติถอยจากจุดที่กระแสแรง ส่วนตัวที่แปรสภาพแล้วอยู่ตามแอ่งซึ่งรับมานาจากหลายสาย สัตว์ เครื่องจักร และเงาจากต่างถิ่นจึงมารวมกันได้ เมื่อรู้สึกว่าทางเข้าแอ่งถูกรุก พวกมันจะออกมาตอบโต้พร้อมกัน โอกาสพบเป็นกลุ่ม 2–5 ตัวสะท้อนจำนวนตัวที่เฝ้าอยู่รอบแอ่งเดียวกัน

ให้คงนิสัยและเรื่องรายตัวใน `src/lib/glowLore.js` เช่น สไลม์ยังดูแลเมล็ดตามครอบครัว โคโบลด์ยังใช้ตะเกียงเวร และโกเลมยังจำแบบทางเดินของตัวเอง ผู้เล่นที่เข้ามาช่วงสั้น ๆ ยังไม่สะสมมานามากพอจะแปรสภาพ

### ความลับของภาคต่อ

อารันคืออดีตช่างผลึกที่ผู้เดินทางเรียกว่าปีศาจเมื่อเห็นแสงลามใต้ผิว น้องสาวของเขาเสียชีวิตในเหตุอุโมงค์ถล่มและพบว่าแกนยังเก็บเสียงกับความทรงจำบางส่วนของเธอไว้ เขาเปิดเครื่องให้มานาไหลย้อนเพื่อหาทางนำความทรงจำนี้ไปไว้ในร่างที่มีชีวิต การทดลองทำให้เขตแกนเต็มไปด้วยร่างเรืองแสงและดันมานาส่วนเกินเข้าตามสายผลึก การแปรสภาพที่พบยากตามธรรมชาติมีอยู่ก่อนแล้ว ส่วนคำเตือนที่ปราสาทเกิดจากเหตุเหมืองถล่มและน้ำหลากตามที่บทแรกคลี่คลายไว้

> **ไพร์** “ท่านลองหยุดเครื่องหลังจากได้ยินนางเรียกชื่อหรือยัง?”
>
> **อารัน** “เคย เสียงนางหายไปสามวัน วันที่สี่ข้าเปิดมันอีก ข้ารอวันที่ห้าไม่ไหว”

เก็บตัวตนของอารันและคำถามว่าเป็นน้องสาวจริงหรือความทรงจำที่แกนเก็บไว้จนถึงช่วงท้ายของพื้นที่ บอสเดิมทั้งแปดชนิดอยู่ในกลุ่มตัวที่สุ่มพบได้ ส่วนการเผชิญหน้าอารันเป็นฉากเนื้อเรื่องแยกสำหรับพัฒนาต่อ

## วิธีล่าที่เสนอให้พัฒนา

| ขนาดฝูง | โอกาสต่อการสุ่ม |
|---|---:|
| 2 ตัว | 55% |
| 3 ตัว | 30% |
| 4 ตัว | 12% |
| 5 ตัว | 3% |

- **รายชื่อมอนสเตอร์** ใช้ ID จากถิ่นเดิมทั้ง 120 ชนิด บังคับสถานะเรืองแสงทุกตัวทุกเวลาในพื้นที่ใหม่ ใช้รูปและบันทึกสมุดมอนสเตอร์เดิม ให้น้ำหนักตามประเภทเพื่อรักษาความหายากของหัวหน้าและบอส ค่าเริ่มต้นสำหรับทดสอบต่อช่องคือปกติ 87% หัวหน้า 10% บอส 3% สุ่มชนิดภายในประเภทโดยหลีกเลี่ยง ID ซ้ำในฝูง ใช้แหล่งรายชื่อเดิมเป็นต้นทางเพื่อให้การ์ด ราคา และสมุดมอนสเตอร์ยังอ้างถึงตัวเดียวกัน
- **การต่อสู้** แสดงศัตรู 2–5 ตัวพร้อมกันและบันทึกเป็นหนึ่งการปะทะ คิดพลังตั้งต้นต่อมอนสเตอร์เป็น `monPower(mon) × 2` รวมพลังศัตรูทั้งฝูงแล้วค่อยประเมินโอกาสชนะของทีม ใช้ ×2 คงที่ในพื้นที่นี้ทั้งสองช่วงเวลา จัดผลสกิลที่เดิมชนะศัตรูหนึ่งตัวโดยอัตโนมัติให้มีผลตามขอบเขตที่เหมาะกับฝูง โดยเฉพาะอุกกาบาต ชุบชีวิต การ์ดพลิกเกม และยา
- **ต้นทุนพลังกาย** ใช้พลังกายตามจำนวนตัวในฝูง จ่ายครบก่อนเริ่มทั้งกรณีชนะและแพ้ ใช้พลังกายประจำวันก่อนยอดสะสมรายชั่วโมง ถ้าพลังกายไม่พอ ให้รอพร้อมแสดงจำนวนที่ต้องใช้ เก็บผลสุ่มฝูงที่รอไว้กับเซฟเพื่อให้รีโหลดหรือสลับแท็บแล้วรอบเดิมยังเหมือนเดิม โอกาสเฉลี่ยของตารางคือ 2.63 ตัวต่อฝูง หากจ่ายแค่ 1 พลังกาย จะมีสิทธิ์ทอยดรอปเฉลี่ย 2.63 ตัวต่อพลังกายเมื่อชนะทุกครั้ง
- **ดรอป** เมื่อชนะทั้งฝูง ให้คำนวณของต่อมอนสเตอร์หนึ่งครั้งตามสูตรร่างเรืองแสงเดิม รวม Trophy วัสดุ ของหายาก เศษทอง คริสตัล การ์ดธรรมดา และการ์ดเรืองแสง วัสดุและชุดของหายากอิงถิ่นต้นทางของ ID แต่ละตัว ใช้ช่วงเวลาของรอบนั้นกับตัวคูณดรอปกลางคืนและคืนเพ็ญเดิม แล้วรวมผลลงกระเป๋าครั้งเดียว กรณีแพ้ไม่ได้ดรอป
- **สมุด การ์ด และความคืบหน้า** ชนะแล้วอัปเดตสมุดและการ์ดของแต่ละ ID ตามผลจริง เก็บจำนวนชนะและบอสของพื้นที่ใหม่แยกจากถิ่นต้นทาง เพื่อให้การเจอบอสเก่าที่นี่ไม่เปิดบทหรือเพิ่มตัวนับบอสของแผนที่เดิม คง XP ต่อชัยชนะหนึ่งรอบและเพดาน XP เดิมเป็นค่าเริ่มต้น
- **การเข้าแผนที่** ใช้ชัยชนะเจ้าแห่งเงาที่ปราสาทเดิมเป็นจุดเปิดเรื่องพื้นที่ใหม่ ส่วนเกณฑ์พลังและเงื่อนไขเพิ่มเติมให้ทดสอบก่อนกำหนด แนะนำให้พื้นที่นี้เป็นจุดหมายที่เลือกเอง เพื่อไม่ให้การวนล่าอัตโนมัติของแผนที่เดิมพาทีมเข้าไปเจอฝูงโดยไม่ตั้งใจ

รักษาดรอปต่อตัวตามโจทย์แล้วเทียบ **Trophy, การ์ดเรืองแสง, คริสตัล และเศษทองต่อ 100 พลังกาย** กับการล่าถิ่นเดิมในช่วงเวลาเดียวกัน แยกผลของทีมช่วงเริ่มเข้าแผนที่จากทีมท้ายเกมที่ชนะสม่ำเสมอ ตัวที่เรืองแสงทุกตัวมี Trophy การใช้พลังกายตามขนาดฝูงกับพลัง ×2 จึงช่วยคุมกำไร แต่ยังต้องวัดว่าทีมท้ายเกมทำให้ของเรืองแสงไหลเข้าเร็วไปหรือไม่ หากเกินเป้าให้ปรับพลัง ต้นทุน หรือโอกาสพบก่อนเปลี่ยนสูตรดรอป

## จุดเชื่อมต่อในโค้ด

- `src/lib/farmData.js` มีถิ่นต้นทาง รายชื่อ ID ประเภท และพลังพื้นฐาน อย่านำ ID เดิมไปลงซ้ำในฟิลด์ที่ใช้สร้าง `MON_BY_ID` เพราะจะเขียนทับความสัมพันธ์ถิ่นต้นทางและกระทบราคา Trophy
- `src/lib/farm.js` มี `fight`, `winChance`, `rareOf` และสูตรดรอปปัจจุบัน สร้างทางเดินสำหรับการล่าแบบใหม่โดยใช้ชุดคำนวณดรอปร่วม และรักษาการล่าทีละตัวของแผนที่เดิม
- `src/lib/rpg.js` มี `farmFight` สำหรับพลังกาย มานา XP ล็อก และการล่าชดเชยเมื่อกลับเข้าเกม รองรับทั้งผลแบบเดิมกับผลแบบฝูงและบันทึกพร้อมกันในรอบเดียว ใช้เวลาจริงของแต่ละรอบในการล่าชดเชย
- `src/components/FarmKit.jsx`, `FarmScene.jsx` และ `HuntFull.jsx` แสดงสนาม รายการมอนสเตอร์ และล็อกการล่า แสดงจำนวนสมาชิกฝูง พลังรวม ผลการต่อสู้ และการ์ดหลายใบได้ทั้งโหมดปกติ โหมดเต็มจอ และการสรุปย้อนหลัง
- `src/lib/worldLore.json`, `src/lib/farmLore.js` และ `src/components/IslandAtlas.jsx` เป็นตำแหน่งเพิ่มภูมิศาสตร์และตอนอ่านใหม่ตอนสร้างพื้นที่จริง เก็บเฉลยเรื่องอารันไว้หลังการเดินทางเข้าเขตแกน

## ตรวจให้ครบก่อนส่งคืน

- ทุกฝูงมี 2–5 ตัว เรืองแสงครบแม้ตอนกลางวัน และรายชื่อที่สุ่มได้ครอบคลุม 120 ชนิดเดิม
- ขอบช่วงสุ่มให้ความน่าจะเป็นตามตาราง และมอนสเตอร์แต่ละตัวใช้พลังพื้นฐานและประเภทจากแหล่งเดิม
- พลังกายไม่พอแล้วรอฝูงเดิม พลังกายพอดีเริ่มได้ และแพ้แล้วไม่เพิ่มของหรือความคืบหน้า การล่าชดเชยใช้ต้นทุนและกติกาเดียวกัน
- ชนะฝูงที่มีบอสเดิมแล้วดรอปและสมุดถูกต้อง โดยบทเดิมและตัวนับบอสในถิ่นต้นทางไม่เปลี่ยน
- เปิดเซฟเดิมและเล่นแผนที่ทั้งแปดได้ รวมการอ่านล็อกเดิม การล่าอัตโนมัติ รอบกลางคืน และรางวัลเดิม
- ทดสอบการแสดงฝูง 5 ตัวและผลหลายรายการบนมือถือ จากนั้นรายงานอัตราชนะและของต่อ 100 พลังกาย พร้อมแยกช่วงเริ่มต้นกับท้ายเกม
