# Life Quest — ต้นฉบับโลกและหลักการเขียน

ฉบับเรียบเรียงใหม่ 27 พฤศจิกายน 2569 อ้างอิงขอบเขตเกมเดิมที่ commit `cca0bbf10e804a1cafdbb5560bedb415b0f63af1`

## ภาพรวมที่ผู้เล่นต้องเข้าใจก่อน

Life Quest เริ่มที่หมู่บ้านในหุบเขาทางใต้ของทวีป แผนที่ของกิลด์ครอบคลุมหมู่บ้านกับถิ่นผจญภัยแปดแห่งแรก ผู้เล่นสร้างชีวิต รู้จักคนในเมือง และออกสำรวจถิ่นที่ขาดการติดต่อ สิ่งที่ทำในชีวิตจริง เช่น ดูแลเงิน อ่านหนังสือ เรียนรู้ และออกกำลังกาย ช่วยพัฒนาตัวละครกับเมือง

ผู้คนตามเส้นทางเหล่านี้เคยติดต่อค้าขายกันผ่านทางเกวียน ทางน้ำ และสถานีส่งข่าว เหมืองถล่มทำให้เส้นทางขนแร่ปิดลง ข่าวจากตอนเหนือของเขตสำรวจจึงห่างหาย แผนที่ที่เมืองมีอยู่เก่ากว่าสภาพจริง ผู้เดินทางนำสิ่งที่พบกลับมาให้กิลด์ตรวจและห้องสมุดเก็บไว้

เมืองมีงานประจำ อาหาร ความสัมพันธ์ และเรื่องขำของตนเอง ชุมชนมอนสเตอร์มีเหตุผลในการอยู่ตรงนั้น ความขัดแย้งอาจมาจากเขตรัง การขาดแคลน ความเข้าใจต่างกัน การลักของ หรือหน้าที่ซึ่งไม่มีผู้ยกเลิก

## แยกสิ่งที่ระบบแสดง

- สถานที่ผจญภัย: ทุ่ง ป่า เหมือง หนอง ทะเลทราย หิมะ ภูเขาไฟ ปราสาท เป็นภูมิศาสตร์จริงในเรื่อง
- ระดับเมือง แดนหมอกหนี้ หมู่บ้านเริ่มต้น เมืองการค้า ปราสาทมั่งคั่ง และอาณาจักรทองคำ แสดงความก้าวหน้าตามฐานะของเมืองที่ตั้งอยู่ในหุบเขาเดิม
- การเงินและกิจวัตร: เป็นข้อมูลของผู้เล่นที่เกมนำมาแสดงความก้าวหน้าและให้กำลังใจ ไม่ใช้เป็นต้นกำเนิดของมอนสเตอร์ทุกตัว
- Shadow Army: ร่างเงาของฮีโร่ที่ใช้รูปชุดและวิชาจากบันทึกกิลด์ บางแบบอ้างนักเดินทาง บางแบบอ้างนิทานหรือสมุดภาพต่างถิ่น ชุดนักบินและนักเดินทางนอกฟ้ามีที่มาจากสื่อเหล่านี้
- เงาในปราสาท: ความทรงจำของผู้เฝ้างานซึ่งยังติดกับหน้าที่ในคืนเกิดเหตุ แยกจากเวทสร้างร่างเงาของฮีโร่
- ไพ่: เรื่องเล่าฝั่ง Life Quest เป็นตัวอย่างประกอบความหมายไพ่ ไม่จำเป็นต้องเป็นเหตุการณ์ที่เกิดพร้อมกันในเส้นเรื่องหลัก

## ภูมิศาสตร์

| สถานที่ | ตำแหน่ง | ชีวิตและความเชื่อมโยง |
|---|---|---|
| หมู่บ้านเริ่มต้น | หุบเขาตอนใต้ | ศาลากลาง ตลาด ห้องสมุด จุดพักคาราวาน |
| ทุ่งหญ้าลมเย็น | ตะวันออกของหมู่บ้าน | แปลงอาหาร กังหัน ทางเกวียนไปป่า |
| ป่าลึกเงาไม้ | ถัดจากทุ่งไปตะวันออก | เขตหากิน เผ่าก็อบลิน ภูต ทางขึ้นเหมือง |
| ถ้ำเหมืองร้าง | หน้าผาทางเหนือของป่า | บ้านโคโบลด์เก่ากับทางที่ปิดหลังถล่ม |
| หนองน้ำหมอกม่วง | ใต้เหมือง ตะวันออกเฉียงใต้ของป่า | สวนลอย หลักร่องน้ำ น้ำไหลผ่านทุ่งลงสู่เมือง |
| ทะเลทรายทองคำ | พ้นช่องผาตะวันออกเฉียงเหนือของเหมือง | คาราวานตามบ่อน้ำ หอแผนที่ของสฟิงซ์ |
| ภูเขาหิมะนิรันดร์ | เหนือทะเลทราย | ต้นน้ำ ค่ายเยติ จุดพัก หอส่งข่าว |
| ภูเขาไฟเพลิงกาฬ | ตะวันตกของแนวเขาหิมะ | โรงหลอมเอฟรีท ทางขึ้นที่ราบสูง |
| ปราสาทเงา | ที่ราบสูงเหนือโรงหลอม ระหว่างหิมะกับภูเขาไฟ | ศูนย์รับข่าวเดิมและต้นทางคำเตือน |

เหมืองอาคารในเมืองเป็นจุดทำงานคนละเขตกับแผนที่ถ้ำเหมืองร้าง ทางบกกับทางน้ำเป็นเส้นทางหลายสาขา ลำดับเปิดแผนที่ตามระดับผู้เล่นยังใช้เงื่อนไขเดิม

## ลำดับเหตุการณ์ของปริศนา

1. หลายรุ่นก่อน ช่างหลายชุมชนสร้างสถานีส่งข่าวด้วยผลึกที่รับแรงสั่นได้ ปราสาทเป็นหอกลาง ระฆังเป็นอุปกรณ์ปลายทางอย่างหนึ่ง
2. การขนอาหารและแร่ทำให้หมู่บ้านติดต่อกับป่า เหมือง และคาราวานต่างถิ่น
3. หลายปีก่อน เหมืองถล่ม ผู้ดูแลหอกลางสั่งปิดทางอันตราย หอกลางเสียหายก่อนส่งคำยกเลิก ผู้เสียชีวิตและความทรงจำบางส่วนกลายเป็นเงา
4. ทางขนแร่ถูกปิด คนเมืองคิดว่าเหมืองร้างทั้งหมด แต่ครอบครัวโคโบลด์บางส่วนยังอยู่ในโพรงปลอดภัย
5. น้ำหลากล่าสุดเปิดและเชื่อมรอยต่อผลึกเก่า เสียงจากคืนเกิดเหตุจึงดังซ้ำ อธิบายปริศนาในเหมืองและสถานีโดยตรง
6. กิลด์เทียบรายงานจากแต่ละถิ่นจนแยกวันเกิดอุบัติเหตุออกจากวันที่เสียงเก่ากลับมา ก่อนตรวจพบหลักฐานที่ปราสาท
7. หลังกลับจากปราสาท ปิ่นแก้แผนที่ให้เห็นว่าโคโบลด์ยังอยู่ในโพรงชั้นบนและทางขนแร่ชั้นล่างยังอันตราย คนขับเกวียนได้สำเนาพร้อมธรรมเนียมผิวปากก่อนเข้าโค้ง เงาและเสียงตกค้างยังเป็นเหตุให้กลับไปสำรวจได้
8. ผลึกจากเหมืองและโรงหลอมสว่างพร้อมกันหลังระฆังเงียบ ไพร์ตามแนวสายแร่ไปถึงขอบแผนที่ของกิลด์ จุดกำเนิดของกระแสยังเป็นปริศนาในบทปัจจุบัน

สัตว์และชุมชนอื่นมีเรื่องตามสภาพแวดล้อมของตน รอยตราช่างใช้บอกที่มาได้โดยไม่จำเป็นต้องเป็นคำใบ้คดีเสมอไป

## ร่างเรืองแสง

ผลึกใต้ทวีปเก็บมานาไว้ เมื่อรอยแตกหรือกระแสไหลย้อนปล่อยมานาออกมา สิ่งที่สัมผัสอาจแปรสภาพหากร่างเก็บมานาไว้ได้พอดี สัตว์อาจรับผ่านอาหาร น้ำ หรือรอยแผล เครื่องจักรและโกเลมรับผ่านแกน ส่วนวิญญาณรับผ่านพลังที่ยึดร่างหรือความทรงจำไว้ แสงออกมาจากร่างที่เปลี่ยนและยังอยู่หลังแยกออกจากแหล่งเดิม จึงพบเพียงบางตัว ตกค่ำเห็นชัดขึ้น และคืนเพ็ญมีโอกาสพบมากขึ้นตามการล่าของเกม

มานาทำให้การตอบสนองรุนแรงขึ้นตามพฤติกรรมเดิม ตัวที่หวงรังอาจออกไล่พ้นเขต ตัวที่เคยหนีอาจหันกลับมาสู้ และผู้เฝ้าเวรอาจไล่ตามแม้ผู้เดินทางถอยแล้ว เรื่องรายตัวใช้เหตุการณ์เฉพาะ จุดที่เริ่มเปลี่ยน และการกระทำที่ต่างจากร่างปกติ วัสดุที่สะท้อนแสงเอง เช่น ผงเรืองแสงของนักปรุงยา ยังเป็นของใช้ในโลกได้ตามปกติ

รายละเอียดเนื้อเรื่องและการล่าในเขตแกนผลึกเวทอยู่ใน [เอกสารส่งต่องาน](CRYSTAL_CORE_HANDOFF_TH.md) ชื่ออารันและจุดประสงค์ของเขาเป็นข้อมูลสำหรับภาคต่อ

## ตัวละครและธรรมเนียมที่ยึดร่วมกัน

- ปิ่นเป็นเด็กฝึกห้องสมุด ครูสอนให้คัดตรงต้นฉบับ ระบุที่มา และเว้นคำถามเมื่อยังไม่รู้ บทอ่านหกช่วงค่อย ๆ พัฒนาไปจนเป็นบรรณารักษ์
- ชาวนารู้จักแปลงและครอบครัวสไลม์ พ่อค้ารู้คาราวาน ชาวประมงรู้ร่องน้ำ ยามรู้เวลาเข้าออก ความรู้ของแต่ละคนมีขอบเขต
- ลูน่าเคยดูแลค่ายหิมะ ไพร์ศึกษาผลึกและแบบช่าง ฟินอ่านรอยกับเครื่องหมายทาง แต่ละคนมีบทบาทที่ใช้ต่อใน Gear และ Skill
- ก็อบลินแขวนของส่วนกลางไว้บนคาน หยิบแล้วคืนก่อนค่ำ นักขโมยบางกลุ่มนำกฎไปใช้กับสินค้าคนอื่นจนเกิดปัญหา
- ถุงใบแรกของก็อบลินมีปมที่ผู้ใหญ่ช่วยผูกหนึ่งปม ที่เหลือต้องทำเอง ปากถุงใช้เชือกสามเส้นถัก จึงเป็นของติดตัวที่มีความหมาย
- สไลม์เก็บเมล็ดในความชื้น ใช้ใบหญ้าจำครอบครัว ราชาสไลม์ดูแลคลังเมล็ดส่วนกลาง
- เอฟรีทเป็นชุมชนช่าง มีทั้งงานเครื่องมือกับสถานีส่งข่าว โคโบลด์มีครอบครัวและเวรงานของตน
- ชื่อไอเทมเชิงการเงิน เช่น ดาบตำนานปลดหนี้ เป็นชื่อพิธีหรือสัญลักษณ์ในบันทึกเมือง รักษาค่าความสามารถและเงื่อนไขเดิม

## วิธีเรียบเรียงข้อความ

เริ่มด้วยสิ่งที่ผู้อ่านเห็นหรือคนในเรื่องกำลังทำ จากนั้นบอกเหตุ แล้วจบด้วยรายละเอียดที่จำได้ ระบุผู้กระทำให้ชัด หากมีคำเฉพาะให้บอกความหมายครั้งแรก อย่าแทนเหตุผลด้วยคำเปรียบเทียบหลายชั้น

ข้อความสถานที่ตอบว่าอยู่ที่ไหนและมีใครอยู่ มอนสเตอร์ตอบว่ามีวิถีอย่างไรและขัดแย้งกับผู้ผ่านทางเพราะอะไร ไอเทมตอบว่ามาจากใครหรือใช้ในชีวิตเจ้าของอย่างไร รายละเอียดเดียวกันต้องตรงกันทั้งกลางวัน กลางคืน ของรางวัล และบทสนทนา

ทุกบทใช้พื้นที่แสดงเดิม ไม่เพิ่มการส่งของ เลือกคำตอบ ซ่อมสถานี หรือภารกิจที่ระบบยังไม่มี

## วิธีเขียนคำพยากรณ์

Bazi ใช้ดิถีหรือธาตุจากวันเกิดเป็นจุดอ้างอิง เปิดด้วยความหมายของคำที่แสดงในผัง แล้วชวนเอาไปเทียบกับสถานการณ์จริงของช่วงที่เลือก รายวัน รายยาม รายปี และเสาโชคแสดงช่วงของตัวเอง คำอธิบายศัพท์จีนและเหตุผลคะแนนอยู่ในรายละเอียดของผัง

มหาทักษาเริ่มจากดาวเสวยซึ่งเป็นหัวข้อหลักระยะยาว แล้วอ่านดาวแทรกภายในช่วงวันที่แสดง คำอ่านคู่ดาว 64 คู่ใช้ภาษาคุยกัน เชื่อมความหมายของดาวทั้งสองกับหนึ่งเรื่องที่ผู้อ่านลองคิดหรือทำได้จริง

คำอ่านทั้งสองส่วนเป็นข้อเสนอให้ทบทวนชีวิต ใช้สถานการณ์จริงประกอบ ระดับคะแนนเป็นค่าของระบบ ชื่อดาวหรือศัพท์ในผังควรมีคำอธิบายก่อนนำไปตีความเป็นเหตุการณ์

คำอ่านไพ่เริ่มจากความหมายและชวนสังเกตภาพบนไพ่ จากนั้นเสนอเรื่องที่ลองทำได้ตามมุมตั้งตรงหรือกลับหัว ส่วนคำถามก่อนนอนอ้างถึงเรื่องของไพ่ใบนั้น ตำนาน Life Quest เป็นเรื่องสั้นประกอบความหมายของไพ่ และคำอธิบายภาพ RWS มีพื้นที่ให้อ่านแยกจากคำอ่านประจำวัน
